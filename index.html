My learning journey

Everything below is something I’ve actually studied, in the order I learned it.

  1. How the web works

    Client and server, requests and responses, IP addresses, and how a browser turns HTML into a page.

  2. HTML

    Semantic layout, lists, images, links, tables, and iframes. Built a Netflix header and an Amazon home page.

  3. Forms and validation

    Input types, GET and POST, and regular expressions in the pattern attribute for passwords and phone numbers.

  4. Bootstrap

    The grid system, cards, modals, carousel, accordion, and navbar. Built a registration page and an EMI calculator.

  5. CSS

    Selectors, the box model, positions, Flexbox, Grid, media queries, transforms, and transitions.

  6. JavaScript

    Starting soon, so my pages can react to clicks, forms, and data.
